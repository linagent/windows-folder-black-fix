# 文件夹黑块修复工具 v2.0.0

适用于 Windows 10/11 中资源管理器里的文件夹图标、文件夹缩略图突然出现黑色背景或黑块的情况。

## 最简单的用法

1. 双击 `文件夹黑块修复工具.exe`。
2. 把出现黑块的文件夹直接拖进窗口；也可以点“选择文件夹”。支持一次加入多个文件夹。
3. 点“一键修复”。没有需要设置的选项。
4. 任务栏和已经打开的文件夹窗口会短暂消失，再自动恢复。这不是电脑重启。
5. 重新打开原文件夹查看效果。第一次打开时，Windows 可能需要几秒钟重新生成缩略图。

建议先等问题再次出现时再运行，以便确认修复是否命中实际症状。现在没有黑块时，无需预防性运行。

## 工具会做什么

- 只处理你加入列表的文件夹，不扫描整块磁盘，也不递归修改子文件夹。
- 如果目标文件夹存在 `desktop.ini`，先做可校验的备份，再把原文件改名停用。
- 清除目标文件夹的“自定义外观”只读/系统标记，并保存原属性以便恢复。
- 清理当前 Windows 账户自动生成的图标缓存和缩略图缓存。
- 重启资源管理器，并通知 Windows 刷新文件夹显示。

## 不会做什么

- 不会删除照片、视频、文档或其他个人文件。
- 不会删除 `desktop.ini` 引用的 `.ico` 自定义图标文件。
- 不会处理磁盘根目录、Windows、Program Files、Program Files (x86) 或 ProgramData。
- 不会修改注册表、安装服务、联网、上传数据或重启电脑。

## 备份与恢复

备份默认保存在：

```text
%LOCALAPPDATA%\FolderBlackFix\Backups
```

需要撤销时，点界面底部的“恢复上次修改”，再选择文件夹，即可恢复该文件夹最近一次备份。恢复时如果已经出现新的 `desktop.ini`，新文件也会先改名保留，不会覆盖丢失。

点“打开备份位置”可以查看所有备份。为避免误删，工具不会自动清理备份或停用的 `.bak` 副本。

## 注意事项

- 运行前请先完成资源管理器中正在进行的复制、移动或重命名操作，因为修复会重启资源管理器。
- 一般不需要管理员权限。受权限保护、网络断开或只读介质上的文件夹可能无法修改；工具会显示警告，不会把失败说成成功。
- 缩略图缓存清理后，首次浏览大量图片或视频时会暂时变慢，这是 Windows 正在重新生成缓存。
- 如果黑块同时出现在桌面、任务栏或许多应用中，原因可能是显卡驱动或系统渲染异常，本工具不应被视为已经修好那类问题。

## 文件说明

- `文件夹黑块修复工具.exe`：Windows 64 位单文件版，已包含运行环境。
- `SHA256.txt`：EXE 的完整性校验值。
- `源码`：完整 C#/.NET 8 WinForms 源码，可自行审查与构建。

此 EXE 为本地构建的未签名开源工具，没有商业代码签名证书。Windows 因此可能显示来源提醒；请先用 `SHA256.txt` 核对文件，再决定是否运行。
